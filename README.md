# Syoka（ショーカ）

**Syoka** は、登録したRSS（最大10サイト）から **各サイト最新5件** の候補を一覧表示し、**選んだ記事だけ**を「紹介記事」として **下書き（draft）作成**できる WordPress プラグインです。  
ランダム生成は行わず、**手動で確認してから作成**する運用に特化しています。

---

## 特徴

- RSSサイトを **最大10件** 登録
- 各サイトの **最新5記事** を候補として表示
- チェックして選んだ記事だけを **紹介記事として下書き作成**
- **重複防止**（同じ元URL/GUIDは作成しない）
- 画像取得に失敗した場合、本文先頭に **「ここに画像が入ります」** の目印を自動挿入
- RSS取得はキャッシュ（transient）して高速化（手動更新も可能）

---

## 動作環境

- WordPress 6.x 推奨
- PHP 8.1+ 推奨（ホスティング環境に依存）
- 管理画面からプラグインを操作できる権限（通常は管理者）

---

## インストール

1. このリポジトリを `wp-content/plugins/syoka/` に配置  
2. WordPress 管理画面 → **プラグイン** → **Syoka** を有効化

---

## 使い方

### 1) RSSサイトを登録（最大10件）
管理画面メニュー：**Syoka → RSSサイト管理**

- RSS URL を追加
- 有効/無効を切り替え
- （任意）取得テストで、候補が表示されるか確認

> 10件を超える追加はできません。

### 2) 候補一覧から選んで下書き作成
管理画面メニュー：**Syoka → 候補一覧**

- 各サイトごとに **最新5件** が表示されます
- 作成したい記事にチェック
- **「選択した記事を下書きで作成」** をクリック

作成後は、投稿一覧から編集できます。

---

## 作成される「紹介記事」の内容

- **投稿ステータス**：常に `下書き（draft）`
- **タイトル**：RSSのタイトル
- **本文**：
  - 画像が取得できた場合：アイキャッチを設定（可能な範囲で）
  - 画像が取得できなかった場合：本文先頭に目印を挿入

### 画像が無いときの目印（例）
本文先頭に以下のような表示が入ります（手動で画像を貼るための合図です）：

```html
<div style="border:2px dashed #ccc; padding:12px; margin:0 0 16px; text-align:center; font-weight:700;">
ここに画像が入ります（後で手動でアイキャッチを設定してください）
</div>
