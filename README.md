# Syoka（ショーカ）

**Syoka** は、RSSから紹介したい記事を選び、紹介記事の下書きを作る **独立Webアプリ** です。

WordPressプラグインではありません。  
WordPressに依存せず、PHPが動くサーバーへ設置して利用します。

---

## 主な機能

- RSSを **最大10サイト** 登録
- RSSごとに **最新5記事** を候補表示
- 画像・タイトル・URL・日付・紹介文候補を取得
- 記事を確認して、選択したものだけを下書き保存
- 同じGUIDまたは元URLの重複保存を防止
- 画像が無い場合は **「ここに画像が入ります」** と表示
- 下書きでタイトル・紹介文・画像URLを手動編集
- 完成HTMLをワンクリックでコピー
- RSSキャッシュ10分＋手動再取得
- ログイン保護
- CSRF対策
- RSS URLのSSRF対策
- PC / スマートフォン対応

---

## 必要環境

- PHP 8.1 以上
- PDO_SQLite
- cURL
- SimpleXML
- mbstring 推奨
- 書き込み可能な `data/` ディレクトリ

データベースサーバーは不要です。

初回セットアップ時にSQLiteデータベースを自動作成します。

---

## インストール

1. このリポジトリ一式をWebサーバーへ配置します。
2. ブラウザで `install.php` を開きます。
3. Syoka管理画面用のログインIDとパスワードを設定します。
4. セットアップ完了後、`login.php` からログインします。
5. 「RSSサイト管理」からRSSを登録します。

---

## Apache

同梱の `.htaccess` で、内部ファイルや `data/` ディレクトリへのWebアクセスを拒否します。

サーバー側で `AllowOverride` が無効になっている場合は、Webサーバー設定側で同等のアクセス制限を設定してください。

---

## Nginx

Nginxでは `.htaccess` が使用されないため、少なくとも `data/` と `app.php` への直接アクセスを拒否してください。

例：

```nginx
location ^~ /data/ {
    deny all;
}

location = /app.php {
    deny all;
}
