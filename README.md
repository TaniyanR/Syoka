# Syoka（ショーカ）

**Syoka** は、登録したRSS（最大10サイト）から **各サイト最新5件** の候補を一覧表示し、選んだ記事だけを「紹介記事」として **下書き（draft）** で作成する WordPress プラグインです。

ランダム生成や自動投稿は行いません。候補を確認してから手動で選択して下書きを作成します。

## 主な機能

- RSSサイトを最大10件登録
- RSSごとに有効 / 無効を切り替え
- 各サイトの最新5記事を候補表示
- 画像 / タイトル / 元記事URL / 日付を確認
- 選択した記事だけを標準投稿の下書きとして作成
- GUIDまたは元記事URLによる重複防止
- 投稿済み候補は選択不可
- RSS画像を取得できた場合はアイキャッチとして保存
- 画像が無い、または画像保存に失敗した場合は本文先頭に「ここに画像が入ります」の目印を挿入
- RSS取得結果を10分間 transient キャッシュ
- 「更新（再取得）」で対象RSSのキャッシュを削除

## 動作環境

- WordPress 6.0 以上推奨
- PHP 8.1 以上

## インストール

### GitHubのZIPを使う場合

1. GitHubの **Code → Download ZIP** でZIPを取得します。
2. WordPress管理画面の **プラグイン → 新規プラグインを追加 → プラグインのアップロード** を開きます。
3. ZIPを選択してインストールします。
4. **Syoka** を有効化します。

プラグイン本体 `syoka.php` はリポジトリ直下に配置しているため、GitHubから取得したZIPをそのままWordPressへアップロードできます。

### 手動設置する場合

リポジトリ一式を `wp-content/plugins/syoka/` に配置し、WordPress管理画面からSyokaを有効化してください。

## 使い方

### 1. RSSサイトを登録

WordPress管理画面の **Syoka → RSSサイト管理** を開きます。

- RSS URLを入力
- 必要に応じて有効 / 無効を設定
- 最大10サイトまで登録可能
- URLの編集、削除も同じ画面で実行可能

### 2. 候補を確認

**Syoka → 候補一覧** を開きます。

有効なRSSごとに最新5件が表示されます。

表示内容：

- 選択チェックボックス
- 画像
- タイトル
- 元記事への確認リンク
- 日付
- 投稿済み / 未投稿

最新状態を取得したい場合は、各RSSの **更新（再取得）** を押してください。

### 3. 紹介記事を下書き作成

紹介したい候補をチェックして **選択した記事を下書きで作成** を押します。

作成される投稿は必ず標準投稿 `post` の **下書き（draft）** です。

本文には次の内容が入ります。

- RSSの説明文から作った短い抜粋（存在する場合）
- 「元記事を読む」リンク
- 出典RSSへのリンク

画像を取得できた場合はメディアライブラリへ保存してアイキャッチに設定します。

画像が取得できない、または保存に失敗した場合は本文先頭に次の目印を挿入します。

```html
<div style="border:2px dashed #ccc; padding:12px; margin:0 0 16px; text-align:center; font-weight:700;">ここに画像が入ります（後で手動でアイキャッチを設定してください）</div>
```

## 重複防止

作成した投稿には以下のpostmetaを保存します。

- `_syoka_source_guid`
- `_syoka_source_url`

同じGUIDまたは同じ元記事URLがすでに存在する場合は新しい下書きを作成しません。

## セキュリティ

- 管理画面は `manage_options` 権限を確認
- 更新操作はnonceで保護
- RSS URLはhttp / httpsのみ受け付け
- 候補作成時はPOSTされた外部URLを直接信用せず、登録済みRSSと候補ハッシュから対象記事を再照合
- 入出力はWordPress標準関数でサニタイズ / エスケープ
